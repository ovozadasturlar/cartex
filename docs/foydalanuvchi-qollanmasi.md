# Cartex — To'liq foydalanuvchi qo'llanmasi

Cartex'ni sozlash va ishlatish — qadamma-qadam, oddiy tilda. Har bo'limda qayerga kirish, nimani bosish va nimani yoqish/o'chirish aniq ko'rsatilgan. Yashil yo'l ko'rsatkichlar (masalan **Sozlamalar → Tizim → Ilova**) — dastur ichidagi yo'l.

## 1. Tez yo'l ko'rsatkich

«Menga X kerak — qayerga kiraman?» savollariga eng qisqa javoblar. Yashil zanjir — dastur ichidagi yo'l: har bo'g'in siz bosadigan bo'lim yoki tugma.

| Nimani xohlaysiz? | Qayerga kirasiz? |
|---|---|
| Qarzga savdoni yoqish | **Sozlamalar → Tashkilot → Savdo siyosati → Qarzga sotish** — 7-bo'lim |
| Oflayn savdoni yoqish | **Sozlamalar → Tizim → Ilova → Oflayn kassa keshi** — 25-bo'lim |
| Qoldiq tugasa ham sotish | **Savdo siyosati → Ombor va katalog → Qoldiq yetarli bo'lmasa ham sotishga ruxsat** |
| Chek printerini ulash | **Sozlamalar → Tizim → Chop etish → Chek** — 20-bo'lim |
| Chekni qayta chiqarish | **Savdo tarixi → Chekni ochish → Chop etish** — 10-bo'lim |
| Bonus (cashback) yoqish | **Sozlamalar → Tizim → Sodiqlik → Sozlamalar › Bonus › Faol** — 8-bo'lim |
| Avtomatik chegirma (aksiya) | **Sodiqlik → Chegirmalar → Qoida qo'shish** |
| Smena talabini yoqish | **Savdo siyosati → Qarz va smena → Smena talabi** — 9-bo'lim |
| Yig'uvchi–kassir navbatini yoqish | **Savdo siyosati → Qo'shimcha imkoniyatlar → Savatni navbatga qo'yish** |
| Yangi kassir qo'shish | **Sozlamalar → Kirish huquqi → Foydalanuvchilar** — 22-bo'lim |
| Dollar (valyuta) qo'shish | **Sozlamalar → Tizim → Valyuta kurslari** — 24-bo'lim |
| Qarz eslatmalari (SMS/Telegram) | **Sozlamalar → Tizim → Qarz eslatmalari** |
| Chekni mijozga Telegram'da yuborish | **Sozlamalar → Dasturchi → Integratsiyalar → Chek yuborish** — 26-bo'lim |
| Barkod etiketka chiqarish | **Chap menyu → Barkod chop etish** — 16-bo'lim |
| Telefonni serverga ulash | **Sozlamalar → Tizim → Ilova → Telefonni ulash** — 3-bo'lim |
| USB kalit bilan kirish | **Sozlamalar → Dasturchi → USB kalitlar** — 23-bo'lim |
| Imkoniyatni yoqish-o'chirish | **Sozlamalar → Dasturchi → Tarif va imkoniyatlar** — 27-bo'lim |

> **Muhim:** Qo'llanmadagi tugma yoki bo'lim sizda ko'rinmasa, buning ikki sababi bo'ladi: **(1)** rolingizda shu ruxsat yo'q — administratordan so'rang; **(2)** imkoniyat tarifda yoki sozlamalarda o'chiq. Cartex'da ruxsati yo'q narsa umuman ko'rinmaydi.

## 2. Cartex haqida va lug'at

*Platformalar: Desktop · Web · Store · Agent*

Cartex — do'kon uchun to'liq savdo tizimi. To'rt xil ilova bitta serverga ulanadi, shuning uchun bir joyda kiritilgan ma'lumot hamma qurilmada darrov ko'rinadi:

- **Desktop** (kompyuterda) — asosiy ish joyi: kassa, ombor, mijozlar, hisobotlar, barcha sozlamalar. Printer va skanerlar shu yerga ulanadi.
- **Web** (brauzerda) — desktop bilan deyarli bir xil: menyusi, sahifalari va sozlamalari o'sha-o'sha. O'rnatish shart emas — brauzerda ochiladi. Qo'llanmada «Desktop» deyilgan hamma narsa web'da ham shu tartibda ishlaydi.
- **Store** (telefonda) — do'kon xodimi ilovasi: kamera bilan skanerlash, telefonda sotish, kirim, mijoz qarzini qabul qilish. Ish tartibi biroz farq qiladi — 17–18-bo'limlarda alohida tushuntirilgan.
- **Agent** (telefonda) — ko'chma savdo agenti ilovasi: katalog, buyurtma, marshrut, mashinadagi yuk — 19-bo'lim.

Har bo'lim boshidagi kulrang yorliqlar shu bo'lim qaysi ilovalarga tegishli ekanini ko'rsatadi.

### Lug'at: tez-tez uchraydigan so'zlar

| So'z | Ma'nosi |
|---|---|
| Savat | Hozir sotilayotgan mahsulotlar ro'yxati — chek yakunlanmaguncha shu yerda turadi. |
| Chek | Yakunlangan savdoning hujjati. Chop etiladi va mijozga elektron ko'rinishda yuborilishi mumkin. |
| Proforma (oldindan chek) | Savdo hali yakunlanmagan savatning hisob-kitob qog'ozi. Ustida «OLDINDAN KO'RISH — CHEK EMAS» yozuvi bo'ladi — bu to'lov hujjati emas. |
| Qaytim | Mijoz ortiqcha bergan naqd pulning qaytariladigan qismi. |
| Avans (haqdorlik) | Mijozning do'kondagi «plyus» puli: ortiqcha to'lov yoki qaytarishdan yig'iladi, keyingi xaridda ishlatiladi. |
| Qarz limiti | Mijozga qarzga berish mumkin bo'lgan eng katta summa. Bo'sh qoldirilsa — cheklanmagan. |
| Smena | Kassirning ish davri: kassani ochish (boshlang'ich pul) va yopish (pulni sanash) orasidagi vaqt. |
| Z-hisobot | Smena yakuni hujjati: kutilgan naqd, sanalgan naqd, farq, savdo va kassa harakati. |
| Kirim | Omborga tovar kiritish hujjati (ta'minotchidan qabul qilish). |
| Qoldiq | Ombordagi mavjud miqdor. Sozlamaga qarab minusga ham tushishi mumkin. |
| Vakolat (oflayn) | Internetsiz ishlash huquqi. Butun biznesda faqat bitta qurilmada bo'ladi — 25-bo'lim. |
| Navbat (sinxron) | Internetsiz qilingan amallarning ro'yxati — aloqa qaytganda serverga o'zi yuboriladi. |
| Tarif / imkoniyat | Dasturning qaysi bo'limlari ochiq ekanini belgilaydigan to'plam — 27-bo'lim. |
| Rol / ruxsat | Har xodim nimani ko'rishi va qila olishini belgilaydigan sozlama — 22-bo'lim. |

## 3. O'rnatish va birinchi kirish

*Platformalar: Desktop · Web · Store · Agent*

### 3.1 Server manzilini kiritish

Dastur birinchi ochilganda serverga ulanishi kerak. Kirish oynasida **«Server bilan aloqa yo'q — manzilni tekshiring»** chiqsa:

1. Kirish oynasining pastidagi **«API manzili»** tugmasini bosing (server ikonkasi bilan).
2. Server manzilini yozing. Masalan: `http://192.168.1.10:5015` (do'kon ichidagi server) yoki administrator bergan internet manzili.
3. **«Saqlash»** ni bosing. `http://` yozishni unutsangiz ham bo'ladi — dastur o'zi qo'shadi.
4. **«Server bilan aloqa o'rnatildi»** (yashil) chiqsa — tayyor.

Keyinchalik bu manzil **Sozlamalar → Tizim → Ilova → API manzili** maydonidan o'zgartiriladi. Web ilova esa to'g'ridan-to'g'ri server manzilida ochiladi — unga alohida sozlash kerak emas.

### 3.2 Kirish usullari

1. **Login va parol** — «Foydalanuvchi nomi» va «Parol» ni yozib **«Kirish»** ni bosing. **«Meni eslab qol»** belgilansa, keyingi safar qayta yozish shart emas. Parol maydonining o'ng tomonidagi ko'z ikonkasi parolni ko'rsatadi/yashiradi.
2. **USB kalit** — administrator USB fleshkaga kalit yozib bergan bo'lsa, fleshkani tiqing: **«USB kalit bilan kirish»** tugmasi o'zi paydo bo'ladi. Bir fleshkada bir necha profil bo'lsa, **«Qaysi profil bilan kirasiz?»** ro'yxatidan tanlaysiz.
3. **QR kod (telefon orqali)** — **«QR kod orqali kirish»** ni bosing, ekranda QR chiqadi. Telefondagi Cartex ilovasida shu QR'ni skanerlang va **«Kirishni tasdiqlash»** ni bosing — kompyuter o'zi kiradi. QR ma'lum vaqtda o'zi yangilanadi (progress chizig'i ko'rsatib turadi).

> **Eslatma:** USB kalit va QR usullari ko'rinishi uchun ular **Sozlamalar → Tashkilot → Tashkilot → Kirish usullari** blokida yoqilgan bo'lishi kerak (23-bo'lim).

### 3.3 Telefon ilovasini serverga ulash

1. Kompyuterda **Sozlamalar → Tizim → Ilova** ni oching.
2. **«Telefonni ulash»** kartasida QR kod turadi.
3. Telefondagi Cartex ilovasining kirish ekranida **«Server QR»** ni ochib shu QR'ni skanerlang — server manzili o'zi to'ladi. Keyin login-parol bilan kirasiz.

### 3.4 Bitta ilova — bitta server (muhim qoida)

Ilova bir vaqtning o'zida **faqat bitta serverga** ulanadi: qaysi manzil sozlangan bo'lsa, hamma ma'lumot o'shanda saqlanadi. Ilova boshqa (eski) serverga fonda ulanishga urinmaydi va o'zi u yoqqa-bu yoqqa almashmaydi — bu ataylab shunday:

- **Ikki server = ikki baza.** Lokal serverda yozilgan savdo bulutdagi bazada yo'q va aksincha. Avtomatik almashinuv do'kon ma'lumotini ikkiga bo'lib yuborardi, keyin ularni birlashtirib bo'lmaydi (tovar — jismoniy narsa, ikki nusxada sotilmaydi).
- **Internet uzilganda server almashtirilmaydi** — buning uchun *oflayn kassa keshi* bor: o'sha serverning ma'lumoti bilan ishlab turadi va aloqa qaytganda o'sha serverga yuboradi (25-bo'lim).
- Serverni almashtirish — **ongli sozlash**: QR skanerlash yoki manzilni qo'lda yozish. Xavfsizlik uchun boshqa serverga o'tilganda ilova sizni tizimdan chiqaradi va yangi serverda qaytadan kirishni so'raydi (parolingiz begona serverga yuborilmaydi).
- Yuborilmagan oflayn amallar bo'lsa, server almashtirishga ruxsat berilmaydi — avval ularni sinxronlang yoki faylga chiqarib oling.

> **Do'kon uchun maslahat:** Do'konda bitta asosiy server bo'lsin: yo do'kondagi kompyuter, yo bulut. Telefon va boshqa kassalar doim o'shanga ulansin. «Ba'zan lokal, ba'zan bulut» rejimi hisobotlarni ham, qoldiqni ham buzadi.

### 3.5 Til va mavzu

Kirish oynasining pastki o'ng burchagida: mavzu tugmasi (**«Yorug'»** / **«Qorong'u»**) va til bayrog'i (o'zbek lotin, kirill, rus, ingliz). Kirgandan keyin ham yuqori paneldan almashtirsa bo'ladi. Telefonda: Profil → Sozlamalar → «Til» va «Mavzu».

## 4. Yangi do'konni sozlash

*Platformalar: Desktop · Web*

### 4.1 Boshlang'ich sehrgar

Birinchi marta kirganingizda (biznes hali sozlanmagan bo'lsa) **«Cartex'ga xush kelibsiz»** oynasi ochiladi. 4 qadam:

1. **Biznes nomi** va **valyuta**ni kiriting.
2. **Do'kon turini tanlang** — mos sozlamalar avtomatik qo'llanadi:
  - **Universal do'kon** — standart, hammasi qo'lda tanlanadi;
  - **Minimarket / oziq-ovqat** — yaroqlilik muddati, tarozi barkodi, cashback;
  - **Kiyim-poyabzal** — o'lcham-rang variantlari, cashback;
  - **Qurilish mollari** — metr/kub o'lchovlar, USD narxlar, mijoz qarzi;
  - **Elektronika / telefon** — USD narxlar, qarz va muddatlar;
  - **Dorixona** — partiya va yaroqlilik muddati nazorati.
  Keyin xohlagan sozlamani qo'lda o'zgartirsa bo'ladi.
3. **Filial** nomi va manzilini kiriting.
4. **«Yakunlash»** ni bosing.

### 4.2 Ish boshlashdan oldingi ro'yxat

1. **Kategoriyalar** — **Sozlamalar → Katalog → Kategoriyalar**: mahsulot guruhlari (masalan: Ichimliklar, Shirinliklar). Ota kategoriya tanlab daraxt qursa bo'ladi — kassada shu guruhlar tugma bo'lib chiqadi.
2. **O'lchov birliklari** — **Sozlamalar → Katalog → Birliklar**: dona, kg, litr allaqachon bor. Kasr miqdorda sotish (masalan 1,5 kg) uchun birlikda **«Haqiqiy songa ruxsat»** belgilangan bo'lishi kerak.
3. **Mahsulotlar** — chap menyudan **Mahsulotlar**: qo'lda yoki Excel orqali kiriting. Har mahsulotga nom, kategoriya, birlik, sotish narxi va barkod kerak.
4. **Kirim** — chap menyudan **Ta'minot**: birinchi kirimni kiriting, qoldiqlar paydo bo'ladi (13-bo'lim).
5. **Xodimlar** — rollar va foydalanuvchilar (22-bo'lim).
6. **Printer** — chek printeri va etiketka printeri (20-bo'lim).
7. **Savdo qoidalari** — **Sozlamalar → Tashkilot → Savdo siyosati**: qarz, chegirma, smena qoidalarini do'koningizga moslang (21-bo'lim).

> **Maslahat:** Avval bitta sinov savdosi qilib ko'ring: mahsulot skanerlang, to'lov oling, chek chiqaring va uni qaytaring. Shunda butun zanjir ishlayotganiga ishonch hosil qilasiz.

## 5. Savdo jarayoni (kassa)

*Platformalar: Desktop · Web — Telefonda sotish — 17-bo'lim*

Chap menyudan **Kassa** ni oching. Ekran ikkiga bo'lingan: chapda mahsulotlar, o'ngda **Savat**. O'rtadagi ajratgichni sichqoncha bilan surib kengaytirsa bo'ladi.

### 5.1 Mahsulotni savatga qo'shish (3 yo'l)

1. **Skaner bilan** — kursor yuqoridagi **«Shtrixkodni skanerlang...»** maydonida turadi (`F2` — shu maydonga qaytish). Skaner o'qigan mahsulot darrov savatga tushadi. Qo'lda barkod yozib `Enter` bossangiz ham bo'ladi.
2. **Plitkadan** — mahsulot kartochkasini bosing. Kartochkada rasm, chegirma bo'lsa qizil **-N%** yorlig'i, nom, narx, kod va qoldiq ko'rinadi. Yuqori o'ngdagi tugma bilan plitka/ro'yxat ko'rinishini almashtirasiz.
3. **Kategoriya bo'yicha** — yuqoridagi kategoriya tugmalari (birinchisi **«Barchasi»**). Tanlangan kategoriyada ichki guruhlar bo'lsa, ikkinchi qator chiqadi. Ro'yxat oxirida **«Yana yuklash»** — davomini ochadi.

Mahsulot haqida to'liq ma'lumot: kartochkani (yoki savatdagi qatorni) **bosib ushlab turing** — tafsilot oynasi ochiladi: rasm, kategoriya, birlik, qoldiq, narx, SKU, shtrixkod. Shu oynadan **«Qo'shish»** (savatga), **«Tahrirlash»** (ruxsat bo'lsa) va **«Kirim qilish»** (5.7) mumkin.

### 5.2 Savatdagi qatorni boshqarish

- **Miqdor**: **−** / **+** tugmalari yoki raqamni qo'lda yozish (kasr ham mumkin, birlik ruxsat bersa).
- **Narx**: narxni o'zgartirish ruxsati bo'lsa, narx tahrirlanadigan maydon bo'ladi; bo'lmasa faqat ko'rinadi.
- **Summa orqali miqdor**: mahsulotda shu rejim yoqilgan bo'lsa, qator jami tahrirlanadi — summani yozasiz, miqdor narxdan o'zi hisoblanadi (masalan: 10 000 so'mlik konfet).
- **O'chirish**: qator oxiridagi **✕**. Butun savatni tozalash — chelak ikonkasi (**«Bekor qilish»**), tasdiq so'raladi.
- Qoldiqdan ortiq yozsangiz qator **qizil** bo'ladi — mavjud miqdor ko'rsatiladi. Sotish o'tish-o'tmasligi siyosatga bog'liq (21-bo'lim).
- **Izoh**: savat sarlavhasidagi **(i)** ikonkasi — savdoga izoh yoziladi (chekda ham chiqarish mumkin).

### 5.3 Mijozni biriktirish

Savat tepasidagi **«Mijoz»** panelini bosing:

1. Qidiruvdan toping va tanlang, yoki **«Mijoz qo'shish»** bilan yangisini yarating (Ism va Telefon majburiy).
2. Mijoz kartasi (barkodli karta) bo'lsa — kartani skan maydonida skanerlang, mijoz o'zi biriktiriladi.
3. Biriktirilgach panelda: ism, bonus (🎁), **«Qarzdor»**/**«Haqdor»** holati va **«Qolgan limit»**. Olib tashlash — **✕**.

Mijoz qachon shart? Qarzga sotishda, bonus bilan to'lashda va avansdan foydalanishda — doim (pul uning hisobiga yoziladi). Qolgan hollarda **Savdo siyosati → Savdoda mijoz** sozlamasiga bog'liq.

### 5.4 Savdoni yakunlash

Pastdagi **«Savdoni yakunlash»** (`F9`) — to'lov qabul qilish alohida bo'limda batafsil: 6-bo'lim. Yakunlangach **«Savdo yakunlandi»** chiqadi va **chek oynasi** ochiladi:

- **«Chop etish»** — chekni chiqarish (avto chop yoqilgan bo'lsa o'zi chiqqan bo'ladi);
- **«Qaytarish»** — shu chek bo'yicha qaytarish (11-bo'lim). Bu tugma chek **Savdo tarixi**dan ochilganda ko'rinadi; hozirgina yakunlangan savdoda uning o'rnini «Tuzatish» bosadi;
- **«Tuzatish»** — savdoni bekor qilib savatni qayta ochish: xato mahsulot yoki narxni to'g'rilab qayta yakunlaysiz (sabab yoziladi; qancha muddatgacha mumkinligi siyosatda);
- **«Mijozni biriktirish»** — savdo paytida unutilgan bo'lsa keyin ham biriktiriladi (cashback siyosatga qarab hisoblanadi);
- **«Yangi sotuv»** — oynani yopib keyingi mijozga o'tish.

### 5.5 Savdoni kutishga olish

Mijoz pul olib kelguncha savatni yo'qotmaslik uchun **«Kutish»** (`F6`): savat lokal saqlanadi, kassa bo'shaydi. Qaytarish: savat tepasidagi **pauza** ikonkasi (sonli) → ro'yxatdan tanlab **«Davom ettirish»**. Keraksizini **«O'chirish»** bilan o'chirasiz, **«Oldindan ko'rish»** — proformasini chiqaradi.

### 5.6 Navbat: yig'uvchi va kassir alohida ishlasa

**Savdo siyosati → Qo'shimcha imkoniyatlar → Savatni navbatga qo'yish** yoqilgan bo'lsa:

1. **Yig'uvchi** savatni yig'ib **«Navbatga yuborish»** (yuqoriga o'q ikonkasi) ni bosadi.
2. **Kassir** **«Navbat»** (☰, sonli nishon) oynasini ochadi: chapda savat kartochkalari, o'ngda tanlangani. **«Davom ettirish»** — savat kassaga yuklanadi, to'lov olinadi. **«Bekor qilish»** — savatni o'chiradi.
3. Telefondagi Store ilovasidan ham savat yig'ib navbatga yoki to'g'ridan-to'g'ri kassaga yuborsa bo'ladi (17-bo'lim).

Boshqa xodim olib qo'ygan savatni majburan olish alohida ruxsat talab qiladi. Bu imkoniyat o'chiq bo'lsa, navbat ikonkalari umuman ko'rinmaydi.

### 5.7 Kassadan turib kirim qilish

Tovar keldi-yu, kassadan uzoqlashib bo'lmaydimi? Mahsulot kartochkasini bosib turing → **«Kirim qilish»**: yetkazib beruvchi, miqdor, **«Sotib olish narxi»**, **«Sotish narxi»**, kerak bo'lsa yaroqlilik muddati → **«Kirim qilish»**. Tovar shu zahoti omborga qo'shiladi. To'liq kirim hujjati bilan ishlash — 13-bo'lim.

### 5.8 Onlayn buyurtmalar

«Onlayn buyurtma» imkoniyati yoqilgan bo'lsa chap menyuda **Buyurtmalar** bo'limi chiqadi: kelgan buyurtmalarni ko'rish va POS'ga olib yakunlash. Buyurtma savati skaner orqali kod bilan ham ochiladi.

### 5.9 Tezkor tugmalar

| Tugma | Vazifasi |

| `F4` | Aniq summa (naqd) — «To'lanadigan»ni naqdga yozadi |
| `F5` | Yangilash |

| `Ctrl+Tab` | Oxirgi sahifalar orasida o'tish |

## 6. To'lov qabul qilish

*Platformalar: Desktop · Web — Telefonda — 17-bo'lim*

Pastdagi panelda doim **«Jami»** ko'rinib turadi. Panelni kengaytirish tugmasi (**«To'lov ma'lumotlari»**) to'liq to'lov qismini ochadi.

### 6.1 Oddiy to'lov (bitta valyuta)

1. **«Naqd»**, **«Karta»**, **«Bonus»** maydonlariga olingan pulni yozing. Bir savdoda bir nechtasini aralashtirish mumkin (masalan yarmi naqd, yarmi karta).
2. Aniq naqd summa uchun **Σ** tugmasi (`F4`) — «To'lanadigan» summani naqd maydoniga o'zi yozadi.
3. Bonus bilan to'lash uchun mijoz biriktirilgan bo'lishi shart — bonus uning hisobidan yechiladi.
4. **«Savdoni yakunlash»** ni bosing.

### 6.2 Chegirma berish

- **«Chegirma»** qatorida ikkita maydon: **%** va **so'm** — biri yozilsa ikkinchisi o'zi hisoblanadi.
- **=** tugmasi — mijoz bergan pul yetmasa, yetmagan summani chegirmaga yozib beradi (chegirma ruxsati bo'lsa ko'rinadi).
- **«Sodiqlik chegirmasi»** qatori — aksiya qoidalari bo'yicha avtomatik chegirma (8-bo'lim); qo'lda bosish shart emas.
- Chegirma chegarasi **Savdo siyosati → Cheklovlar → Maksimal chegirma, %** da belgilanadi; undan oshish alohida ruxsat talab qiladi.

### 6.3 Qaytim yoki mijoz hisobiga

Ortiqcha pul berilsa **«Qaytim»** qatori chiqadi. Mijoz biriktirilgan bo'lsa va siyosatda **«Mijoz haqdor bo'lishi mumkin»** yoqilgan bo'lsa, «Qaytim» yozuvini bosib **«Hisobga»** ga almashtirasiz — ortiqcha pul mijoz avansiga yoziladi va keyingi xaridda ishlatiladi.

### 6.4 Kam to'lansa — qarz

To'lanmagan qism qizil **«Qarz»** qatorida chiqadi va mijoz hisobiga yoziladi. Batafsil: 7-bo'lim.

### 6.5 Aralash to'lov (ko'p valyuta rejimida)

Ko'p valyuta yoqilgan bo'lsa (24-bo'lim) Naqd/Karta maydonlari o'rniga **«Aralash to'lov»** qatorlari chiqadi:

1. Har qator: **usul** (Naqd, Karta, Mobil o'tkazma, Bank o'tkazmasi, Bonus) + **valyuta** + **summa**. Yonida **≈** bilan asosiy valyutadagi qiymati ko'rinadi.
2. **«To'lov qo'shish»** — yana qator qo'shadi (masalan: 100$ naqd + qolgani so'mda karta).
3. Kurs eskirgan bo'lsa sariq ogohlantirish chiqadi — bosilsa **«Kurslarni yangilash»** oynasi ochiladi (kurs ruxsati bo'lsa).
4. Qarz qolsa **«Qarz valyutasi»** ni tanlaysiz — qarz qaysi valyutada yozilishini belgilaydi.

## 7. Qarzga savdo

*Platformalar: Desktop · Web · Store*

### 7.1 Qarzga savdoni yoqish

1. Yuqori o'ngdagi **Sozlamalar** ni oching.
2. Chapdan **Tashkilot → Savdo siyosati** ga kiring.
3. **«Qarz va smena»** kartasini toping.
4. **«Qarzga sotish»** o'tkazgichini yoqing — izoh o'zgaradi: *«Mijoz to'lamagan qismi uning qarziga yoziladi»*.
5. Xohlasangiz **«Qarz muddati majburiy»** ni ham yoqing — har qarz savdosida to'lov sanasi kiritilishi shart bo'ladi va eslatmalar shu sanadan ishlaydi.
6. Yuqoridagi **«Saqlash»** ni bosing.

### 7.2 Kassada qarzga sotish

1. Mijozni biriktiring (qarz mijozsiz mumkin emas — dastur o'zi so'raydi).
2. Mahsulotlarni qo'shing, to'lov panelida mijoz to'lagan qismini «Naqd»/«Karta» ga yozing (hech narsa to'lamasa — bo'sh qoldiring).
3. To'lanmagan qism avtomatik qizil **«Qarz»** qatorida ko'rinadi.
4. **«Qarz muddati»** sanasini tanlang (majburiy bo'lsa, tanlanmaguncha yakunlanmaydi).
5. **«Savdoni yakunlash»** — qarz mijoz hisobiga yoziladi.

**Qarz limiti:** Mijozlar → mijozni tahrirlash → **«Qarz limiti»** (bo'sh = cheklanmagan). Limit oshsa kassada qizil **«Qarz limiti oshib ketdi»** banneri chiqadi va savdo o'tmaydi. Mijoz panelida **«Qolgan limit»** doim ko'rinib turadi.

### 7.3 Qarzni qabul qilish (to'lash)

1. Chap menyudan **Mijozlar** → mijozni toping (qator ustiga ikki marta bosing — profili ochiladi).
2. **«Qarzni to'lash»** ni bosing.
3. Summani yozing (**Σ** — to'liq qarz), **«To'lov turi»**: Naqd yoki Karta. Ko'p valyutada qarz valyutasi va to'lov valyutasi alohida tanlanadi.
4. Qarzdan ortiq to'lansa yashil **«Avans»** chiqadi — ortiqchasi mijoz hisobida qoladi.
5. **«Saqlash»**. Siyosatda kvitansiya yoqilgan bo'lsa, to'lov qog'ozi chiqadi.

Telefonda: Store → Mijoz → **«To'lov qabul qilish»** (18-bo'lim).

### 7.4 Qarz eslatmalari (avtomatik SMS/Telegram/Email)

1. **Sozlamalar → Tizim → Qarz eslatmalari** ni oching.
2. **«Avtomatik eslatma yoqilgan»** ni yoqing.
3. Jadvalni sozlang: **«Muddatdan oldin ogohlantirish»** (necha kun avval), **«Muddat kuni yuborish»**, kechikkanlar uchun takrorlash oralig'i, minimal qarz summasi, yuborish soati.
4. **«Yetkazish kanallari»**: Telegram / SMS / Email (kanallar ishlashi uchun avval Integratsiyalar sozlangan bo'lsin — 26-bo'lim).
5. Xabar shablonlarini xohlaganingizcha o'zgartiring: `{name}`, `{balance}`, `{days}`, `{dueDate}` kabi joy tutuvchilar bor. Bo'sh qoldirilsa standart matn ketadi.
6. **«Saqlash»**. Eslatmalar muddati kiritilgan qarzlarga ishlaydi — shu sabab «Qarz muddati majburiy» yoqilgani ma'qul.

### 7.5 Qarz kechirimi

Qarzning bir qismini (yoki hammasini) kechirish «Qarzni to'lash» oynasining ichida qilinadi — desktop, web va telefonda bir xil:

1. Avval yoqing: **Savdo siyosati → Qo'shimcha imkoniyatlar → Qarz kechirimi**; «Cheklovlar» kartasida eng katta kechirim summasi/foizini belgilang (0 — cheklovsiz). Xodimda «Mijoz qarzini kechirish» ruxsati ham bo'lishi kerak — ikkalasisiz maydon umuman ko'rinmaydi.
2. Mijoz profilida **«Qarzni to'lash»** ni oching: to'lov maydoni ostida **«Kechirish»** maydoni turadi (doim 0 dan boshlanadi).
3. Kechiriladigan summani QO'LDA kiriting, yoki **«Qolganini kechirish»** tugmasi bilan to'lovdan keyin qoladigan butun qoldiqni bir bosishda to'ldiring — keyin xohlagancha o'zgartirsa bo'ladi. Masalan: qarz 10 536, mijoz 10 000 berdi — kechirishga 36 yozsangiz, 500 qarz bo'lib QOLADI; 536 yozsangiz, qarz to'liq yopiladi.
4. **«Kechirish sababi»** majburiy — sababsiz saqlanmaydi.
5. **«Qarzda qoladi»** ko'rsatkichi natijani oldindan ko'rsatib turadi. **«Saqlash»** — to'lov va kechirim BITTA hujjatda rasmiylashadi, hisobotda «Qarz kechirildi» bo'lib alohida ko'rinadi.

> **Muhim:** Kechirim HECH QACHON avtomatik yozilmaydi: kam to'lov qilinsa, qoldiq qarzligicha qoladi. Faqat qo'lda kiritilgan summa kechiriladi. To'lovsiz sof kechirim ham mumkin (summa 0, faqat kechirish). Oflayn rejimda kechirim ishlamaydi — internet talab qilinadi.

### 7.6 Kassadan mijozga qarz pul berish

**Savdo siyosati → Qarz va smena → Mijozga qarzga pul berishga ruxsat** ni yoqing va **«Bir martada eng katta qarz»** ni belgilang. Keyin mijoz profilidagi **«Chiqim»** tugmasi orqali: summa mijoz avansidan oshsa, sariq ogohlantirish chiqadi — *«Avansdan oshgani qarzga yoziladi»* — va kassadan pul chiqadi. Alohida ruxsat talab qiladi.

### 7.7 Xato to'lovni bekor qilish

Mijoz profilidagi harakatlar ro'yxatida to'lov yozuvini toping → **«To'lovni bekor qilish»** — tasdiqdan keyin mijoz qarzi avvalgi holatiga qaytadi. Faqat mijoz to'lovini bekor qilish mumkin (savdoni emas — savdo uchun «Tuzatish» yoki qaytarish bor).

## 8. Chegirma va bonus (sodiqlik)

*Platformalar: Desktop · Web*

Hammasi **Sozlamalar → Tizim → Sodiqlik** sahifasida. Uch bo'lim: **Chegirmalar**, **Bonus**, **Sozlamalar**. Yuqorida davr bo'yicha ko'rsatkichlar: berilgan chegirma, chegirmali savdolar, savdodagi ulushi, mijozlardagi bonus qoldig'i.

> **Farqi nimada:** **Chegirma** chek summasini hozir, kassada kamaytiradi — aksiya va maxsus narxlar uchun. **Bonus (cashback)** — mijoz to'liq to'laydi, lekin xariddan bonus yig'adi va uni keyingi xaridda to'lov sifatida ishlatadi. Bonus — mijozni qaytarib keladigan vosita.

### 8.1 Avtomatik chegirma (aksiya) qo'shish

1. **«Chegirmalar»** bo'limida **«Qoida qo'shish»** ni bosing.
2. Nom bering, **«Turi»** ni tanlang: barcha mahsulotlar / bitta mahsulot / kategoriya / ishlab chiqaruvchi.
3. **«Usul»** va **«Qiymat»** (foiz yoki summa). Xohlasangiz: **«Min. summa»** (chek shundan oshsa ishlaydi), **«Boshlanishi»/«Tugashi»** (bo'sh = doimiy), **«Ustuvorlik»** (bir nechta qoida mos kelsa qaysi biri kuchli).
4. Muayyan mijozga maxsus narx kerak bo'lsa **«Mijoz»** ni tanlang (bo'sh = barcha mijozlar).
5. **«Istisno mahsulotlar»** — aksiyaga kirmaydigan tovarlarni chiqarib tashlash.
6. Saqlang — chegirma kassada o'zi qo'llanadi va **«Sodiqlik chegirmasi»** qatorida ko'rinadi.

Ro'yxatda har qoida holati ko'rinadi: **Faol** / **Kutilmoqda** / **Muddati tugagan** / **O'chiq**. Mijozning shaxsiy doimiy chegirmasi mijoz kartochkasidagi **«Chegirma %»** maydonida — u eng ustuvor.

**«Sozlamalar»** bo'limidagi **«Chegirmalarni birlashtirish»**: *«Faqat eng ustuvori qo'llanadi»* yoki *«Mos kelganlari qo'shib hisoblanadi»*.

### 8.2 Bonus (cashback) yoqish

1. **Sodiqlik → Sozlamalar** da «Bonus» ostidagi **«Faol»** ni yoqing.
2. **«Keshbek %»** — har xariddan necha foiz bonus yozilishi. **«Cashback yaxlitlash (so'm)»** — yaxlitlash qadami.
3. Muayyan mahsulot/kategoriyaga boshqa foiz kerak bo'lsa **«Bonus»** bo'limida qator qoidasi qo'shing (foiz yoki donaga belgilangan summa). **«Umumiy %dan istisno»** belgilansa, o'sha qator faqat o'z bonusini beradi.
4. Bonus faqat mijoz biriktirilgan savdoda yoziladi. Do'kon cashback bersa, **Savdo siyosati → Savdoda mijoz** ni **«Qarz va bonusda»** qilib qo'ying — to'liq to'langan savdoda ham mijoz so'raladi, aks holda bonus yo'qoladi.
5. Mijoz bonusini keyingi xaridda **«Bonus»** to'lov maydoni orqali ishlatadi.

Savdodan keyin mijoz biriktirilsa cashback hisoblansinmi? **Savdo siyosati → Keyin biriktirilgan savdolarga keshbek hisoblash** o'tkazgichi hal qiladi.

## 9. Smena: kun tartibi

*Platformalar: Desktop · Web — Z-hisobotlar telefonda ham ko'rinadi (Store → Savdo)*

### 9.1 Smena nima uchun kerak

Smena — kassadagi naqd pulni nazorat qilish usuli: kun boshida qancha pul bor edi, kun davomida qancha kirdi-chiqdi, kun oxirida qancha bo'lishi kerak va amalda qancha bor. Farqlar darrov ko'rinadi.

Talab darajasi: **Savdo siyosati → Qarz va smena → Smena talabi** — **«Talab qilinmaydi»** / **«Naqd savdo uchun»** / **«Barcha savdolar uchun»**.

### 9.2 Kun boshi: smena ochish

1. Chap menyudan **Smena** ni oching (yoki kassadagi sariq **«Smena ochilmagan»** tugmasidan).
2. **«Boshlang'ich summa»** ga kassadagi naqd pulni yozing (ko'p valyutada — har valyuta uchun alohida qator).
3. **«Smena ochish»** ni bosing. Kassada yashil **«Smena ochiq»** ko'rinadi.

### 9.3 Kun davomida

- Savdolar o'z-o'zidan smenaga yoziladi: naqd/karta savdo, qarzga berilgani, bonus ishlatilgani — hammasi «Savdo» kartasida ko'rinib boradi.
- **Pul olish-qo'yish:** **«Naqd harakati»** qatori — sababni yozing (masalan «tushlik»), xarajat kategoriyasini tanlang, summani kiriting va yashil **«Kirim»** (kassaga qo'shish) yoki qizil **«Chiqim»** (olish) ni bosing. Kategoriyalar **Sozlamalar → Tizim → Xarajat kategoriyalari** da yaratiladi.
- Mijoz qarz to'lovlari va ta'minot to'lovlari (naqd) ham «Kassa harakati» kartasida hisoblanadi.

### 9.4 Kun oxiri: smena yopish va Z-hisobot

1. Kassadagi naqd pulni sanang va **«Sanab kiritilgan naqd»** maydoniga yozing (ko'p valyutada — har valyuta alohida). Yonida **«Kutilgan»** va farq (rangli) ko'rinadi.
2. **«Smena yopish»** ni bosing. Farq bo'lsa tasdiq so'raladi: *«Kassada farq bor: ... Yopishni tasdiqlaysizmi?»*
3. **Z-hisobot** ochiladi: uchta katta karta (**Kutilgan naqd** / **Sanab kiritilgan** / **Farq** — kamomad, ortiqcha yoki teng), savdo yakuni (naqd, karta, qaytarishlar, bonus, qarzga berilgani, savdo soni) va kassa harakati (boshlang'ich, kirim, chiqim, qarz va ta'minot to'lovlari).
4. **«Chop etish»** — Z-hisobotni chiqaradi. Avto chiqishi uchun: **Chop etish → Z-hisobot → Smena yopilganda avto chop etish**.

### 9.5 Smenalar tarixi

Sahifaning pastida **«Smenalar tarixi»**: kim, qachon ochgan-yopgan, boshlang'ich va sanalgan summa, holat. Har qatorda **«Z-hisobot»** ikonkasi — eski hisobotni qayta ochish/chiqarish. Rahbar ruxsati bo'lsa: kassir filtri va ochiq smenani **«Majburiy yopish»** (kutilgan summa bilan yopiladi).

## 10. Chek chiqarish va yuborish

*Platformalar: Desktop · Web · Store — Printerni birinchi marta sozlash — 20-bo'lim*

Bu bo'lim — printer allaqachon sozlangandan keyingi *kundalik foydalanish* haqida.

### 10.1 Savdo cheki

- **Avtomatik:** **Chop etish → Chek → Savdodan keyin chekni avto chop etish** yoqilgan bo'lsa, har savdo yakunida chek o'zi chiqadi.
- **Qo'lda:** savdodan keyingi chek oynasida **«Chop etish»** tugmasi.
- **Qayta chiqarish:** **Savdo tarixi** → chekni oching → **«Chop etish»** (qayta chiqarish alohida ruxsat bilan boshqariladi).

### 10.2 Proforma (oldindan chek)

Savdo yakunlanmasdan mijozga hisob-kitob qog'ozi berish uchun savat sarlavhasidagi **printer** ikonkasi (**«Oldindan ko'rish»**). Chiqqan qog'ozda **«OLDINDAN KO'RISH — CHEK EMAS»** yozuvi bo'ladi. Tugma ko'rinishi **Savdo siyosati → Savat proformasini chop etish** bilan yoqiladi. Kutishdagi savdolar oynasida ham **«Oldindan ko'rish»** bor.

### 10.3 To'lov va chiqim kvitansiyalari

**Savdo siyosati → To'lov va chiqim kvitansiyasini chop etish** yoqilgan bo'lsa: mijozdan qarz to'lovi qabul qilinganda va pul chiqarilganda kvitansiya avtomatik chiqadi. O'chiq bo'lsa pul harakati faqat hisobda qoladi.

### 10.4 Elektron chek (QR va havola)

1. **Sozlamalar → Dasturchi → Integratsiyalar → Chek yuborish** da **«Ommaviy bazaviy URL»** ni kiriting (masalan `https://shop.example.uz`).
2. **Chop etish → Chek → Chek tarkibi** da **«Elektron chek QR kodi»** va/yoki **«Elektron chek havolasi»** ni belgilang — qog'oz chekda QR chiqadi, mijoz uni skanerlasa chek telefonida ochiladi.
3. «Chek yuborish» bo'limida kanallarni belgilang (Telegram / SMS / Email) — chek mijozga o'zi yuboriladi. «Admin chatiga ham nusxa» — egasi har savdoni Telegram'da ko'rib boradi.

### 10.5 Tarmoq printerida chiqarish

Printer boshqa kompyuterga ulangan bo'lsa (20.5 da sozlanadi), chek o'zi o'sha printerga «yo'naltiriladi». Xabarlar:

- **«... chop etildi»** — muvaffaqiyat;
- **«... chop etish navbatiga yuborildi»** — vazifa navbatda, printerli kompyuter bajaradi;
- **«... navbatga qo'yildi, lekin bu tur uchun hozir mos printer onlayn emas»** — printerli kompyuterni yoqing yoki sozlamani tekshiring;
- Muammo bo'lsa: **Chop etish → Tarmoq printerlari → Oxirgi print vazifalari** — holat, xato matni, **«Qayta urinish»** / **«Bekor qilish»**.

### 10.6 Internetsiz chek

Server bilan aloqa yo'q paytda chek shu kompyuterning termal printerida chiqadi: **«... server bilan aloqa yo'q, shu kompyuterning printerida chop etildi»**. Hujjat (A4/A5) rejimi serverni talab qiladi: **«Serversiz faqat termal chek chiqarish mumkin»**.

## 11. Qaytarishlar

*Platformalar: Desktop · Web · Store*

### 11.1 Chekdan qaytarish (eng oson yo'l)

1. **Savdo tarixi**dan chekni oching va **«Qaytarish»** ni bosing — qaytarish muharriri o'sha savdo bilan ochiladi.
2. Har qatorda **«Qaytarish miqdori»** ni kiriting. **«Olingan»** ustuni mijoz jami nechta olganini ko'rsatadi.
3. **«Narx»** — shu mahsulot sotilgan narxlardan tanlanadi.
4. **«Holati»**: Yaroqli / Ochilgan / Shikastlangan / Nuqsonli. **«Yo'nalish»**: Omborga (qayta sotiladi) / Karantin / Chiqindi / Ta'minotchiga da'vo.
5. **«Sabab»** — siyosatda majburiy qilingan bo'lsa yozilishi shart.
6. **«Saqlash»** — «Qaytarish ... saqlandi».

### 11.2 Pul hisobi qanday bo'ladi

Odatda avtomatik: *avval mijoz qarzi kamayadi, ortgani mijoz haqdorligiga (avansga) yoziladi*. Naqd qaytarib berish kerak bo'lsa pastdagi **«Naqd qaytarish»** katagini belgilang — pul kassadan chiqadi. Qaytarish cheki chop etiladi (**«Chop etish»**).

### 11.3 Mijoz bo'yicha qaytarish

**Qaytarishlar → Yangi qaytarish** → mijozni tanlang → **«Mijoz savdolari»** paneli ochiladi: savdolarni belgilab **«Tanlanganlarni yuklash»** — qatorlar o'zi to'ladi. Bir necha chekdan birdaniga qaytarsa bo'ladi.

### 11.4 Chekda yo'q tovarni qabul qilish (erkin qator)

**Savdo siyosati → Qaytarish siyosati → Savdoga bog'lanmagan qaytarish** yoqilgan bo'lsa (va xodimda erkin qator ruxsati bo'lsa): muharrirda **«Mahsulot qo'shish»** qatori chiqadi — mahsulot, soni, narxni kiritib **+** ni bosasiz. Sotilganidan ortiq miqdor yoki boshqa narx ham erkin qator hisoblanadi — dastur ogohlantiradi.

### 11.5 Qaytarish qoidalari (sozlash)

- **«Qaytarish sababi majburiy»** — har qatorda sabab yozish shart.
- **«Bekor qilingan savdoga qaytarish»** — odatda o'chiq tursin: tovar ikki marta kirim bo'lish xavfi bor.

Telefonda qaytarish: Store → savdoni oching → **«Mahsulot qaytarish»** (18-bo'lim).

## 12. Mijozlar

*Platformalar: Desktop · Web · Store · Agent*

### 12.1 Mijoz qo'shish

Chap menyudan **Mijozlar** → **«Qo'shish»**. Maydonlar:

- **«Chegirma %»** — shaxsiy doimiy chegirma (eng ustuvor).
- **«Qarz limiti»** — bo'sh = cheklanmagan.
- **«Boshlang'ich qoldiq»** (faqat yangi mijozda) — avvaldan mavjud qarzi (**Qarzdor**) yoki sizning unga qarzingiz (**Haqdor**). Cartex'gacha daftardagi qarzlarni shu yerdan ko'chirasiz.
- **«Mijoz tili (chek/xabarlar)»** — chek va eslatmalar shu tilda boradi. **«Xabarnoma yubormaslik»** — bu mijozga avtomatik xabar ketmaydi.

### 12.2 Mijoz profili

Ro'yxatda qator ustiga ikki marta bosing. Tepada: qarz (yoki **Haqdor**), bonus, qarz limiti kartalari. Amal tugmalari:

- **«Qarzni to'lash»** — 7.3;
- **«Chiqim»** — mijozga pul berish: avansini qaytarish, avansdan oshsa (ruxsat bo'lsa) qarzga yozish — 7.6;

- **«Xabar yuborish»** — Telegram / SMS / Email kanalida qo'lda xabar (mijozda mos manzil bo'lsa).

### 12.3 Tarix va hisobot

- **«So'nggi tranzaksiyalar»** tabi — har pul harakati: turi (Sotuv, Qarz to'lash, Avans, Keshbek, Qaytim...), o'zgarish va balans.
- **«Savdolar»** tabi — mijozning barcha cheklari.
- **«Hisobot»** tabi — davr tanlab to'liq hisob-kitob: har hujjat, debet-kredit, yakuniy balans; **«Eksport»** — Excel'ga.
- **«Yig'ma dalolatnoma»** (siyosatda yoqilgan bo'lsa) — 1-qadam: hujjatlarni belgilaysiz; 2-qadam: **«Tuzish»** — ishlatilgan tovar, yopilgan summa va qolgan qarz bitta qog'ozda; **«Chop etish»**. Uzoq muddatli mijozlar bilan yakuniy hisob-kitob uchun qulay.

### 12.4 Ro'yxat ekrani imkoniyatlari

Yuqorida uchta ko'rsatkich: mijozlar soni, jami qarz, bonus. Qidiruv, saralash va **«Eksport»** (Excel). Jadvalda qarz ustuni rangli: qizil — qarzdor, yashil — haqdor.

## 13. Kirim qilish

*Platformalar: Desktop · Web · Store — Telefonda kirim — 18-bo'lim*

### 13.1 Kirim hujjatini ochish

Chap menyudan **Ta'minot → Qo'shish**. Hujjat sarlavhasida: **«Ta'minot sanasi»**, **«Ombor»**, **«Yetkazib beruvchi»** (yonida uning joriy qarzi qizil yoki avansi yashil ko'rinadi), ko'p valyutada **«Valyuta»**.

### 13.2 Qator qo'shish

1. **Skaner bilan:** **«Shtrixkodni skanerlang...»** maydonida barkodni o'qiting — qator o'zi qo'shiladi.
2. **Nom bilan:** **«Mahsulot nomi»** ga yozing — ro'yxat chiqadi, `Enter` bilan tanlang. Bazada yo'q nom yozsangiz: *«... bazada topilmadi. Yangi mahsulot sifatida qo'shilsinmi?»* — «Ha» desangiz yangi kartochka ochiladi.
3. Miqdor, birlik yoki qadoqni tanlang. Qadoq (masalan, 20 donalik blok) tanlansa, **«Narx saqlash birligi uchun»** katagi chiqadi — narxni dona uchun yoki blok uchun kiritayotganingizni belgilaysiz; ko'k matn hisobni oldindan ko'rsatadi.
4. **«Sotib olish narxi»** va **«Sotish narxi»** ni kiriting. Kerak bo'lsa **«Yaroqlilik muddati»**.
5. **«Qo'shish»** (yoki `Enter`).

Jadvalda har qator: miqdor, omborga tushadigan hisob, olish/sotish narxi (tahrirlanadi), **«Marja»** va jami. Qator ikonkalari: **«Barkod chop etish»** (etiketka — 16-bo'lim) va **✕**.

### 13.3 Excel'dan import

1. **«Namuna»** tugmasi bilan bo'sh shablonni yuklab oling.
2. Shablonni to'ldiring (nom, miqdor, narxlar...).
3. **«Excel'dan import»** ni bosib faylni tanlang — mos qatorlar muharrirga o'zi qo'shiladi: «N ta qator qo'shildi», mos kelmaganlari sababi bilan ko'rsatiladi.

### 13.4 Saqlash va to'lov

1. Pastda to'rt karta: **Qatorlar** / **Jami** / **Daromad** / **Foyda**. **«Saqlash»** ni bosing.
2. Dastur so'raydi: **«Ta'minot saqlandi. To'lov qilindimi?»** «Ha» desangiz to'lov oynasi ochiladi.
3. To'lov oynasida: **Jami** / **To'landi** / **Qarzda qoladi** / **Jami qarzdorlik** ko'rsatkichlari. Summani kiriting (**Σ** — hammasi), to'lov turini tanlang, **«Qo'shish»** — bir necha bo'lakda (naqd + karta) ham bo'ladi. **«Saqlash»**.
4. To'lanmagan qism ta'minotchiga qarz bo'lib yoziladi — keyin 14-bo'limdagi «To'lov» bilan yopiladi. Shu kuni boshqa to'lov qilingan bo'lsa, oynada **«Shu kundagi to'lovlar»** ro'yxati chiqadi — shu kirimga tegishlisini belgilaysiz.

### 13.5 Kirimni ko'rish, tahrirlash, bekor qilish

Ta'minot ro'yxatida hujjatni oching: qatorlar, to'lovlar, jami. Tugmalar (ruxsatga qarab): **«Tahrirlash»**, **«To'lov»**, **«Kirimni bekor qilish»** — tasdiq bilan qoldiq va to'lovlar teskari qilinadi. **«Eksport»** ro'yxatni Excel'ga chiqaradi.

> **Eslatma:** Ta'minotchisiz kirim mumkinmi — **Savdo siyosati → Ombor va katalog → Kirimda ta'minotchi majburiy** hal qiladi.

## 15. Ombor va ko'chirishlar

*Platformalar: Desktop · Web*

### 15.1 Ombor sahifasi

Chap menyudan **Ombor**: barcha mahsulotlar qoldig'i, **kam qoldiq** (belgilangan minimumdan tushganlar) va **muddati tugayotgan** tovarlar ro'yxati, hamda **inventarizatsiya** — haqiqiy sanoq bilan dastur qoldig'ini solishtirish.

Yuqori paneldagi **ombor tanlagich** — qaysi ombor bilan ishlayotganingizni belgilaydi (kassa ham shu ombordan sotadi).

### 15.2 Bir nechta ombor va ko'chirishlar

- Yangi ombor: **Sozlamalar → Tashkilot → Ombor** — filialga bog'lab yaratiladi. **«Onlayn buyurtmalar ombori»** katagi — onlayn buyurtmalar shu ombordan yig'iladi.
- Ombor ikkitadan oshsa chap menyuda **Ko'chirishlar** paydo bo'ladi — omborlararo tovar o'tkazish hujjatlari.

### 15.3 Filial assortimenti

**Sozlamalar → Tashkilot → Filial → Assortiment**: har mahsulot uchun **«Avto»** / **«Ko'rsatish»** / **«Yashirish»** — mahsulot shu filial kassasida chiqadimi-yo'qmi. Narxi hali belgilanmagan mahsulotlar ko'rinishini **Savdo siyosati → Filial assortimentiga hali kirmagan mahsulotlar ko'rinsin** boshqaradi.

### 15.4 Qoldiq bilan bog'liq qoidalar

- **«Qoldiq yetarli bo'lmasa ham sotishga ruxsat berish»** — yoqilsa qoldiq minusga tushishi mumkin (tez do'konlar uchun qulay), o'chiq bo'lsa ortiq sotish rad etiladi.
- **«Tugagan mahsulotlar kassada ko'rinsin»** — o'chirsangiz kassada faqat qoldig'i borlar chiqadi.
- **«Yangi mahsulot uchun min. qoldiq»** — kam qoldiq ogohlantirishining standart chegarasi.

## 16. Barkod etiketkalar

*Platformalar: Desktop — Printer sozlamalari — 20.4*

2. **Kirimdan:** kirim muharriridagi qatorda **«Barkod chop etish»** ikonkasi — yangi kelgan tovarga darrov yorliq chiqarasiz.

## 17. Store: telefonda sotish

*Platformalar: Store — Do'kon xodimi ilovasi*

Store — telefonni skanerli kassa yordamchisiga aylantiradi. Kirish uchun xodim rolida do'kon ilovasi ruxsati va tarifda **«Do'kon xodimi ilovasi»** yoqilgan bo'lishi kerak. Server manzili QR bilan kiritiladi (3.3).

### 17.1 Ilova tuzilishi (pastki 5 tugma)

| Bo'lim | Nima bor |
|---|---|
| Asosiy | Bugungi tushum, o'rtacha chek, tezkor amallar (Yangi savdo, Navbat, Savat, Kirim qilish), 7 kunlik savdo grafigi. |
| Savdo | Uch tab: Navbat (kutayotgan savatlar), Savdolar (qidiruv bilan, kunlik yakun: naqd/karta/qarzga/avans), Z-hisobotlar. |
| Skaner | Asosiy ish ekrani — kamera bilan barkod o'qish (17.2). |
| Mijoz | Mijozlar ro'yxati va profillari (18-bo'lim). |
| Profil | Ombor tanlash, oflayn rejim, qurilmalar, xavfsizlik, til/mavzu, chiqish. |

**«7 kunlik savdo dinamikasi»** — oxirgi 7 kun (bugun bilan birga) tushumi chizig'i, ostida kun nomlari va tepasida haftalik jami. Kun chegarasi **telefonning o'z vaqt mintaqasida** hisoblanadi, ya'ni kechqurungi savdo o'sha kunga tushadi. Bu 7 kunda umuman savdo bo'lmasa grafik o'rniga **«Hozircha ma'lumot yo'q»** yozuvi turadi — ya'ni bo'sh ekran «savdo bo'lmagan» degani. Ro'yxatni pastga tortib yangilash mumkin.

### 17.2 Skanerlash

1. **Skaner** tabini oching — kamera yonadi: *«Shtrix-kod yoki QR kodni ramkaga oling»*.
2. Mahsulot o'qilgach pastda amal varag'i chiqadi: **«Savatga qo'shish»**, **«Kirim qilish»**, **«Narx»** (ko'rish/tahrir), **«Chop etish»** (etiketka).
3. Barkod bazada bo'lmasa: **«Mavjudiga biriktirish»** (bor mahsulotga qo'shish) yoki **«Yangi qo'shish»**.
4. **Server QR**: kompyuterdagi **«Telefonni ulash»** QR kodini shu asosiy skanerda o'qisangiz ham bo'ladi — ilova «... serveriga ulanilsinmi?» deb so'raydi, tasdiqlasangiz manzilni almashtiradi: sessiyangiz yangi serverda amal qilsa ishlashda davom etasiz, aks holda login sahifasiga o'tadi (manzil allaqachon to'ldirilgan). Bu faqat Cartex'ning O'Z server-QR kodi bilan ishlaydi — mahsulot qutisidagi sayt QR'lari server deb qabul qilinmaydi.
5. **Boshqa QR'lar ham tushuniladi**: sayt havolasi QR'i o'qilsa — «Havolani ochish?» taklifi (brauzerda ochiladi); Wi-Fi QR'i o'qilsa — tarmoq nomi ko'rsatilib, parolni nusxalab Wi-Fi sozlamalarini ochish taklif qilinadi.
6. Kamerasiz qidirish: chap yuqoridagi qidiruv tugmasi — nom bo'yicha izlash, kategoriya tugmalari, **+** yangi mahsulot.
7. O'ng yuqorida ikkita savat tugmasi: **kirim savati** (yuk mashinasi ikonkasi) va **savdo savati** — har birida nechta mahsulot borligi ko'rinadi.

### 17.3 Savat va to'lov

1. Savatni oching: mahsulotlar, miqdorlar, **«Jami»**. Mijozni qidiruv orqali biriktiring. **«Tozalash»** — savatni bo'shatadi (tasdiq bilan).
2. **«Sotuvni yakunlash»** ga o'ting (**Kassa** ekrani): **«Chegirma»** (+ **=** tugmasi), **«To'lanadigan»**, **«Naqd»** (+ **«Aynan»** — aniq summa), **«Karta»**, mijoz bo'lsa **«Bonus»**.
3. Mijozda avans bo'lsa: **«Mijoz avansidan foydalanish»** o'tkazgichi — yetmagan summani avansdan qoplaydi; **«Ortiqcha to'lovni mijoz avansiga o'tkazish»** — qaytim o'rniga hisobga yozadi.
4. Yakunda: **«To'landi»**, **«Qaytim»**, **«Qarzga»** ko'rinadi. Qarzga sotish desktopdagi qoidalar bilan bir xil ishlaydi (7-bo'lim).
5. **«Sotuvni yakunlash»** ni bosing — chek desktop kassa printerida chiqarilishi ham mumkin (tarmoq chop etish sozlangan bo'lsa).

### 17.4 Savatni kassaga topshirish (QR uzatish)

Telefonda yig'ib, pulni kassada olish uchun ikki yo'l:

- **«Navbatga yuborish»** — savat kassirlarning **«Navbat»** oynasiga tushadi (5.6). Navbat imkoniyati (siyosat yoki tarif) o'chiq bo'lsa, bu tugmalar telefonda ham ko'rinmaydi — xuddi desktopdagidek.
- **«Kassaga uzatish»** — ekranda QR chiqadi: *«Kassir shu QR kodni skanerlasa, savat kassada ochiladi»*. Kassir skan maydonida o'qiydi — savat POS'da ochiladi. Holatlar: **Navbatda** → **Kassada** → **Sotildi**.

### 17.5 Desktop bilan farqi (qisqacha)

- Skaner — qurilma emas, telefon kamerasi.
- Kutishga olish (F6) o'rniga savat telefonning o'zida turadi; navbat va QR uzatish bor.
- Sozlamalar (siyosat, printer, rollar) faqat desktop/webda — telefon ularga bo'ysunadi.

## 18. Store: kirim, qarz, qaytarish va boshqalar

*Platformalar: Store*

### 18.1 Telefondan kirim qilish

2. Kirim savatini oching: **«Yetkazib beruvchini qidirish»** orqali ta'minotchini tanlang.
3. Har qatorda **«Kirim narxi»** va **«Sotish narxi»** ni kiriting (kiritilmagani ro'yxat bilan ko'rsatiladi).

### 18.4 Mahsulotni tahrirlash

Skanerdan yoki qidiruvdan mahsulotni ochib **«Tahrirlash»**: rasm (kamera / galereya / havola), nom, narx, artikul, kategoriya, barkodlar (yangisini skanerlab qo'shish), pachka miqdori.

- **Profil → Xavfsizlik**: **PIN kod**, **Biometrika** (barmoq izi), **Qulflash muddati**, **Parolni o'zgartirish**. Telefon do'konda qolsa ham ilovaga begona kira olmaydi.

### 18.6 Telefonda oflayn

Telefon ham oflayn vakolat oluvchi qurilma bo'la oladi — desktop bilan teng huquqda. Barcha oflayn sozlamalari **alohida bo'limda**: **Profil → Oflayn rejim**. Bo'lim boshidagi asosiy **«Oflayn rejim»** tugmasi o'chiq bo'lsa qolgan sozlamalar ko'rinmaydi; yoqilganda Savdo / Qarz to'lovlari / Kirim kataklari, navbat ro'yxati va **«Navbatni faylga chiqarish»** / **«Navbat faylini yuklash»** ochiladi. Tushuncha va qoidalar desktop bilan bir xil — 25-bo'lim.

## 20. Printerlarni sozlash

*Platformalar: Desktop — Kundalik chop etish — 10-bo'lim*

**Sozlamalar → Tizim → Chop etish**. Beshta tab: **Chek**, **Oldindan chek**, **Barkod yorliq**, **Z-hisobot**, **Tarmoq printerlari**. Har tabda o'ngda **jonli ko'rinish** — sozlamani o'zgartirsangiz natija darrov ko'rinadi. Har tabda **«Sinov chop etish»** bor — saqlashdan oldin tekshiring.

### 20.1 Chek printeri

1. **«Chek»** tabida **«Chop turi»** ni tanlang: **«Termal (80mm)»** — chek lentasi (odatiy holat) yoki **«Hujjat»** — oddiy printerda A4/A5 qog'ozga.
2. Termal: **«Chek printeri»** ro'yxatidan tanlang, **«Qog'oz kengligi (belgi)»** — «auto» printer drayveridan kenglikni o'zi aniqlaydi (58mm qog'oz → 32 belgi, 80mm → 48 belgi); ro'yxatda yo'q qiymatni (24–64) qo'lda yozish ham mumkin. **«Chek nusxalari»** — nechta nusxa chiqishi.
3. Termal printer tili: **«Belgilar kodlash»** — chek noto'g'ri/g'alati belgilar bilan chiqsa shu yerdan tuzatiladi (lotin chek uchun CP437, kirill uchun CP866); **«Kod jadvali (ESC t)»** raqami printer modeliga qarab farq qilsa qo'lda o'zgartiriladi. **«Qog'ozni kesish»** — qisman / to'liq / kesilmasin, **«Kesishdan oldin surish»** — kesikdan oldin necha qator bo'sh surilishi. Bular shu kompyuterda saqlanadi — har kassa o'z printeriga mos sozlanadi.
4. Hujjat: printer, fizik qog'oz (A4/A5), yo'nalish (Portret/Albom), bir qog'ozga nechta chek sahifasi (1/2/4) — qog'oz tejash uchun.

### 20.2 Chek tarkibi

«Chek tarkibi» kartasida chekda nima chiqishini belgilaysiz: biznes nomi, filial, manzil, telefon, kassir, mijoz, chek raqami, to'lov tafsilotlari, elektron chek QR/havolasi. **«Chek sarlavha matni»** — masalan STIR; **«Chek yakuniy matni»** — «Xaridingiz uchun rahmat!». Logotip **Sozlamalar → Tashkilot → Tashkilot → Logotip** da yuklanadi — termal chek uchun oq-qora varianti avtomatik yaratiladi.

### 20.3 Oldindan chek (proforma)

**«Oldindan chek»** tabi — proforma ko'rinishini alohida sozlaydi: chop turi, sarlavha/yakuniy matn, nimalar ko'rsatilishi (sotuvchi, mijoz, izoh, savat kodi).

### 20.4 Barkod yorliq (etiketka printeri)

1. Printer va **«Etiketka o'lchami (mm)»** ni kiriting (qog'ozdagi bitta yorliqning eni×bo'yi).
2. **«Etiketka rejimi»**: **tspl** — etiketka printeriga to'g'ridan-to'g'ri buyruq (tavsiya etiladi, tez va aniq); **pdf** — oddiy Windows drayveri orqali.
3. «Etiketka tarkibi»: nom (1/2 qator/to'liq), narx, SKU, valyuta ko'rinishi, harf registri, **«Narx tanloviga ruxsat»**.
4. Yangi rulonda **«Avto-kalibrlash»** ni bosing (faqat TSPL). Chiqish surilsa: **«Gorizontal/Vertikal surish (mm)»**, **«Burilish (°)»**; sifat uchun **«Aniqlik (dpi)»** (203/300), **«Zichlik»** (1–15), **«Tezlik»** (1–6).
5. Ko'rinishda *«Mazmun etiketka chetiga yetib borgan...»* ogohlantirishi chiqsa — o'lcham yoki siljishni to'g'rilang.

### 20.5 Tarmoq printerlari (bitta printer — hamma kassaga)

Bu tab printerni bir kompyuterga ulab, boshqa kassalar (va telefonlar) undan foydalanishi uchun. Tarifda «Tarmoq orqali chop etish» yoqilgan bo'lishi kerak.

1. **Qurilmani ishonchli qiling:** chapdagi «Qurilmalar» ro'yxatida printerli kompyuterni toping va **«Ishonchli»** o'tkazgichini yoqing — endi u print so'rovlarini qabul qiladi va printerlarini tarmoqqa beradi. Sozlash paytida **«Yangi qurilmalarga avtomatik ruxsat»** ni vaqtincha yoqib turish mumkin (keyin o'chiring).
2. **Yo'naltirishni belgilang:** o'ngdagi «Print turi bo'yicha yo'naltirish»da har tur (Chek, Savat, Etiketka, Z-hisobot, Hujjat) uchun printerlarni tartiblang (tutqichdan sudrab), **«Bu print turi faol»** va kerak bo'lsa **«Avtomatik rejim»** (tanlangani ishlamasa istalgan mos onlayn printer ishlatiladi) ni yoqing.
3. **«Yo'naltirishni saqlash»** ni bosing.
4. Nazorat: pastdagi **«Oxirgi print vazifalari»** — har vazifaning holati, xato bo'lsa **«Qayta urinish»** / **«Bekor qilish»**.

> **Diqqat:** «Hozir bu tur uchun printerli birorta ishonchli kompyuter onlayn emas» degan qizil yozuv chiqsa — printer ulangan kompyuter o'chirilgan yoki «Ishonchli» qilinmagan. Topshiriqlar yo'qolmaydi, navbatda kutadi.

## 21. Savdo siyosati — to'liq ma'lumotnoma

*Platformalar: Desktop · Web — Barcha kassalarga birdek ta'sir qiladi*

**Sozlamalar → Tashkilot → Savdo siyosati** — do'konning savdo qoidalari. Har o'tkazgich ostida hozirgi holat nimani anglatishi yozib turadi. O'zgartirgach yuqoridagi **«Saqlash»** ni unutmang. Chegara maydonlarida **0 = «cheklov yo'q»**, «o'chiq» emas.

### Qo'shimcha imkoniyatlar

| Sozlama | Yoqilsa nima bo'ladi |
|---|---|
| Qarz kechirimi | Mijoz qarzidan bir qismini kechirish mumkin — chegara va sabab bilan (7.5). |
| To'lov va chiqim kvitansiyasini chop etish | Qarz to'lovi va pul chiqimida kvitansiya chiqadi. |
| Savat proformasini chop etish | Kassada proforma tugmasi turadi (10.2). |
| Yig'ma dalolatnoma | Mijoz profilida yig'ma hisob-kitob hujjati (12.3). |
| Savatni navbatga qo'yish | Yig'uvchi–kassir rejimi; o'chiq bo'lsa navbat ikonkalari umuman ko'rinmaydi (5.6). |

### Cheklovlar

**«Maksimal chegirma, %»** · **«Eng katta qarz kechirimi, so'm»** · **«Eng katta qarz kechirimi, %»** — hammasi 0 bo'lsa cheklanmagan.

### Savdo talablari

**«Savdoda mijoz»**: **«Faqat qarzda»** / **«Qarz va bonusda»** / **«Har savdoda»**. Qarz, bonus to'lovi va haqdorlik mijozsiz baribir mumkin emas — bu sozlama emas, qoida. Cashback beradigan do'kon «Qarz va bonusda» ni tanlagani ma'qul.

### Qaytarish siyosati

**«Bekor qilingan savdoga qaytarish»** · **«Savdoga bog'lanmagan qaytarish»** · **«Qaytarish sababi majburiy»** — 11-bo'lim.

### Katalog narxi

**«Yuqori narx kiritilsa katalog narxi yangilansin»** — kassir katalogdagidan yuqori narxda sotsa katalog ham yangilanadi; **«...eng katta oshish, %»** — chegaradan oshsa savdo o'tadi, lekin katalog eski narxda qoladi.

## 25. Oflayn rejim (internetsiz ishlash)

*Platformalar: Desktop · Store — Web'dan: holatni ko'rish, uzish, fayl import*

Internet uzilganda savdo to'xtamasligi uchun Cartex'da **oflayn kassa keshi** bor: bitta qurilma ma'lumotlarni o'zida saqlab internetsiz ishlayveradi; aloqa qaytishi bilan hamma amallar serverga o'zi yuboriladi.

> **Muhim tushuncha:** Oflayn vakolat butun biznes bo'yicha faqat **BITTA** qurilmaga beriladi — buni server nazorat qiladi. Bu ataylab shunday: ikkita qurilma bir vaqtda internetsiz sotsa, qoldiqlar chalkashib ketadi.

### 25.1 Yoqish (qadamma-qadam)

1. Imkoniyatni tekshiring: **Sozlamalar → Dasturchi → Tarif va imkoniyatlar → Oflayn kassa (bitta qurilma)** yoqilgan bo'lsin.
2. Asosiy kassa kompyuterida **Sozlamalar → Tizim → Ilova** ni oching.
3. **«Oflayn kassa keshi»** kartasida **«Kassa omborini tanlang»** — shu kassa sotadigan ombor.
4. **«Shu kompyuterda yoqish»** ni bosing. Holat **«Shu kompyuterga yoqilgan»** bo'ladi — dastur kerakli ma'lumotlarni yuklab oladi va yangilab boradi.

### 25.2 Qaysi amallar oflayn ishlaydi

**«Bu qurilmada oflayn imkoniyatlar»** ostidagi kataklar bilan tanlaysiz: **«Savdo»** (naqd/karta, asosiy valyutada) · **«Qarz to'lovlari»** · **«Kirim»** (to'lovsiz, ta'minotchiga qarz bo'lib). Belgilanmagan imkoniyatning ma'lumotlari qurilmaga yuklanmaydi — masalan faqat «Qarz to'lovlari» belgilansa, keshda faqat mijozlar saqlanadi. Oflaynda ishlamaydiganlar: bonus to'lovi, boshqa valyuta, qadoqlash, mahsulot tahrirlash, navbatga yuborish — dastur ochiq aytadi.

### 25.3 Internet uzilganda

- Yuqorida **«Server bilan aloqa yo'q — oflayn rejimda ishlamoqda»** banneri; kassa ishlayveradi.
- Har amal **navbatga** yoziladi; termal chek chiqarish ham ishlaydi.
- Internet qaytishi bilan navbat o'zi serverga yuboriladi — hech narsa bosish shart emas.

### 25.4 Navbatni boshqarish

«Oflayn kassa keshi» kartasida holat satri: **«Yangilangan»** · **«Navbatda»** · **«Xato»**. Server rad etgan amal qizil bo'ladi, uch tugma bor:

- **«Qayta urinish»** — sababni to'g'rilab (masalan, smena ochib) qayta yuborish;
- **«O'tkazib yuborish»** — amalni serverga yozmaslik (tasdiq bilan; amal butunlay qo'llanmay qoladi);
- **«Bekor qilish»** — faqat hali yuborilmagan amalni o'chirish (lokal qoldiq/qarz qaytariladi).

### 25.5 Kompyuter ishdan chiqsa: faylga chiqarish va yuklash

> **Telefon ham qutqaradi:** Navbat faylini **telefon orqali ham** yuklash mumkin: Store ilovasida **Profil → Oflayn rejim → Navbat faylini yuklash**. Ya'ni kassa kompyuteri qotib qolgan bo'lsa, fleshkadagi faylni telefonga o'tkazib, telefondan serverga yuborasiz — kompyuter tuzalishini kutish shart emas.

1. Buzilgan kompyuterda (bir amallik ishlasa ham): **«Navbatni faylga chiqarish»** — navbat JSON faylga saqlanadi (`cartex-navbat-...json`), internetsiz ham ishlaydi. Faylni fleshkaga oling.
2. Istalgan internetli qurilmada (kompyuter, telefon yoki web) **«Navbat faylini yuklash»** ni bosib faylni tanlang.
3. Oynada amallar ro'yxati chiqadi — qaysilari yuklanishini belgilaysiz. **Belgilanmaganlari yo'qolmaydi:** serverda «o'tkazib yuborilgan» deb qayd etiladi, shuning uchun ta'mirlangan kompyuter ularni qayta yubora olmaydi.
4. **«Rad etilganlarni avtomatik o'tkazib yuborish»**: belgilansa xatolar to'xtatmaydi; belgilanmasa birinchi xatoda to'xtaydi (to'g'rilab qayta yuklash mumkin).
5. Natija: qo'llandi / avval qo'llangan / o'tkazib yuborildi / kutmoqda sonlari.

> **Takrorlanish bo'lmaydi:** Ta'mirlangan kompyuter keyin o'z navbatini yuborsa ham, server har amalni belgisidan taniydi — allaqachon qo'llanganlarini qayta yozmaydi.

### 25.6 Vakolatni ko'chirish

- Oddiy yo'l: eski qurilmada **«Uzish»** (navbati bo'sh bo'lsin), keyin yangisida yoqish.
- Eski qurilma o'lgan bo'lsa: yangi qurilmada **«Boshqa qurilmadan offline rejimni bekor qilish»** (qizil tugma). Eski qurilmadagi yuborilmagan amallar o'zi ko'chmaydi — 25.5-fayl orqali oling.

### 25.7 Boshqa kassalarga xalaqit beradimi?

Boshqa (internetli) kassalar ishlayveradi. Faqat **bitta** nuqtada ehtiyot chorasi bor: vakolatli qurilma aloqadan uzilgan paytda **o'sha bitta ombor** bo'yicha bir tovar ikki joydan sotilishi mumkin. Buni qanday hal qilish — o'zingiz tanlaysiz: **Sozlamalar → Savdo siyosati → Oflayn kassa ishlayotganda qoldiq nazorati yumshatilsin**.

| Sozlama | Oflayn kassa aloqasiz bo'lganda |
|---|---|
| **O'chiq** (standart) | O'sha ombordan onlayn savdo vaqtincha **bloklanadi** — qoldiq aniq qoladi, lekin boshqa kassa sota olmaydi. |
| **Yoqiq** | Hech kim bloklanmaydi — savdo davom etadi. Qoldiq minusga tushsa kassirga sariq **«Diqqat: oflayn kassa ishlayotgan bo'lishi mumkin — bu tovar qoldig'i minusga tushdi»** ogohlantirishi chiqadi va bu hodisa audit iziga yoziladi. Qoldiq keyin inventarizatsiya yoki kirim bilan to'g'rilanadi. |

Yumshatish **faqat shu oynada va faqat vakolat omborida** ishlaydi — oddiy kunda qoldiq nazorati o'z kuchida qoladi. Bu bilan «minus qoldiqqa ruxsat» (har doim, hamma yerda ochiq) sozlamasining farqi shu.

> **Oyna abadiy ochiq qolmaydi:** Agar vakolatli qurilma umuman qaytmasa (buzildi, yo'qoldi), do'kon abadiy blokda yoki abadiy minus rejimida qolib ketmasligi kerak. Shuning uchun **24 soatdan keyin** bunday vakolat «tashlab ketilgan» hisoblanadi: blok ham, yumshatish ham bekor bo'ladi, do'kon odatdagidek ishlaydi. Bunday qurilmaning navbati yo'qolmaydi — 25.5 dagi fayl orqali olinadi.

### 25.8 Ma'lumot qanday yangilanib turadi

Birinchi yoqishda qurilma **to'liq** nusxani yuklab oladi (mahsulotlar, narxlar, qoldiqlar, shtrix-kodlar, mijozlar). Undan keyin har yangilanishda faqat **o'zgargan qatorlar** tortiladi — shuning uchun katta katalogda ham yangilanish sekinlashtirmaydi va internet trafigi kam sarflanadi. O'chirilgan yoki savdodan olingan mahsulot ham darhol keshdan chiqariladi.

- Kategoriya, o'lchov birligi, chegirma qoidasi, valyuta kursi yoki savdo siyosati o'zgarsa — bu butun katalogga tegadi, shuning uchun nusxa bir marta **to'liq** yangilanadi.
- Qurilma **7 kundan** ortiq bog'lanmagan bo'lsa ham keyingi ulanishda to'liq yangilanadi.
- Har yangilanishda qurilma sanoqlarni (mahsulot/shtrix-kod/mijoz soni) server bilan solishtiradi; farq chiqsa o'zi to'liq yangilanishni so'raydi — ya'ni kesh jimgina eskirib qolmaydi.

### 25.9 Internet uzilganda boshqa qurilmalar ham ishlasin

Oflayn kesh bitta qurilmani ishlatib turadi. Do'konda 2-3 qurilma bo'lsa, qolganlari internet qaytguncha kutishi kerak edi. **Vaqtinchalik xizmat** shu muammoni yechadi: internet uzilganda vakolatli qurilma do'kon Wi-Fi'sida qolganlarga xizmat ko'rsatadi — ular o'sha qurilma orqali sotishda davom etadi.

1. Vakolatli qurilmada **«Shu tarmoqdagi boshqa qurilmalarga xizmat qilsin»** ni yoqing. Kompyuterda: **Sozlamalar → Tizim → Ilova → Oflayn kassa keshi**. Telefonda: **Profil → Oflayn rejim** — o'tkazgich vakolat shu telefonda bo'lgandagina ko'rinadi.
2. Boshqa qurilmalar shu **bir xil Wi-Fi** ga ulangan bo'lsin — telefon ham, ikkinchi kassa kompyuteri ham. Ularda hech qanday sozlama shart emas: qurilma xizmatni tarmoqdan o'zi topadi. Ba'zi routerlar qurilmalar orasidagi e'lonni bloklaydi — bunday tarmoqda qurilmani bir marta qo'lda ulash kifoya, keyin u manzilni eslab qoladi.
3. Internet uzilganda: vakolatli qurilmada holat **«Do'kon tarmog'iga xizmat qilmoqda»** bo'ladi; qolgan qurilmalarda (telefon va ikkinchi kompyuter) **«Do'kon kassasi orqali ishlamoqda»** deb turadi va savdo odatdagidek davom etadi.
4. Internet qaytishi bilan hamma qurilma o'zi bulutga qaytadi — hech narsa bosish shart emas.

> **Nega bu xavfsiz:** Qurilmalar bir-birini **tarmoqqa ishonib emas**, serverdan olingan imzolangan guvohnoma bilan taniydi. Ya'ni Wi-Fi'ga ulangan begona telefon sizning kassangizga savdo yozib qo'ya olmaydi. Qurilmalar bir-biriga **parol yoki token yubormaydi**, ma'lumot do'kondan tashqariga chiqmaydi. Savdolar bitta navbatda, bitta tartibda turadi — shuning uchun internet qaytganda hujjatlar ikkilanmaydi va bir tovar ikki marta yozilmaydi.

**Telefon ham xizmat qila oladi.** Tok o'chganda kompyuter o'chadi, telefon esa ishlab turadi: vakolatni telefonga bering va shu o'tkazgichni yoqing — qolgan qurilmalar telefon orqali ishlaydi. Bunda telefon bildirishnomasida **«Do'kon tarmog'iga xizmat qilmoqda»** turadi; bu bildirishnomani yopmang — Android uni o'chirsa xizmat ham to'xtaydi.

**Qachon foyda bermaydi:** tok o'chib **router ham** o'chsa, Wi-Fi yo'q bo'ladi va qurilmalar bir-birini topa olmaydi — bunday holatda faqat vakolatli qurilmaning o'zi ishlaydi. Router uchun kichik UPS qo'yish shu muammoni butunlay yechadi.

### 25.10 Telefonda oflayn

Store ilovasida oflayn sozlamalari alohida bo'limda: **Profil → Oflayn rejim**. Bo'lim boshida bitta asosiy tugma — **«Oflayn rejim»**. U **o'chiq** bo'lsa qolgan sozlamalar umuman ko'rinmaydi (profil sahifasi bekorga to'lib ketmaydi). Yoqilganda ochiladi: imkoniyat kataklari (**«Savdo»** · **«Qarz to'lovlari»** · **«Kirim»**), navbat ro'yxati (har qatorda xato sababi va bekor qilish), **«Navbatni faylga chiqarish»** va **«Navbat faylini yuklash»**.

Telefon vakolatni **desktop bilan teng huquqda** oladi: qishda tok o'chib kassa kompyuteri o'chsa, vakolatni telefonga berib savdoni davom ettirasiz. Vakolat baribir bitta qurilmada bo'ladi — telefon olsa, kompyuterda oflayn kesh o'chadi (va aksincha).

Vakolat telefonda bo'lmasa ham telefon ishsiz qolmaydi: internet uzilganda u do'kon kassasini o'zi topib, o'sha orqali sotishda davom etadi (25.9). Bunda oflayn bo'limida **«Do'kon kassasi orqali ishlamoqda»** deb turadi.

## 28. Hisobotlar va moliya

*Platformalar: Desktop · Web*

- **Boshqaruv paneli** — kunlik manzara: bugungi sotuv va foyda, kam qoldiq tovarlar, so'nggi tranzaksiyalar, tezkor amallar. Ish kunini shu yerdan boshlang.
- **Hisobotlar** — davr tanlab: savdo dinamikasi, foyda, qarz eskirishi (kim qancha va qachondan beri qarzdor), ombor qiymati, eng ko'p sotilgan mahsulotlar va eng faol mijozlar. Ko'pini Excel'ga **«Eksport»** qilsa bo'ladi.
- **Hisoblar** — kassa, karta, bonus va qarz hisoblari qoldig'i: do'kon puli hozir qayerda turibdi.
- **Tranzaksiyalar** — barcha pul harakatlari jurnali: har savdo, to'lov, chiqim, qaytarish alohida yozuv bo'lib turadi.

> **Maslahat:** Haftada bir marta «qarz eskirishi» hisobotiga qarang — muddati o'tayotgan qarzlar ko'payib ketmasidan eslatma yuboring yoki qo'ng'iroq qiling.
